# Assets: Agent debrief

Shot list from CONTENT-SPEC.md. Drop files here with these exact names, run `node build.js`, and they replace their placeholders. Both clips carry sound, so they render with visible controls and never autoplay. Captions burned in. Keep each under 90 seconds.

## Lead
- `trust-moment.mp4`: the trust moment, with sound. Chip click, then the artifact scrolls to and pulses the region that decision shaped. Once on a slide, once on HTML.
- `trust-moment-poster.jpg` (optional): poster frame.

## Supporting
- `debrief-turns.mp4`: the spoken turn-taking debrief with voice pushback. With sound.
- `debrief-turns-poster.jpg` (optional): poster frame.
- `still-01.png`, `still-02.png`, ... : supporting stills. Any count works; they render in filename order.
