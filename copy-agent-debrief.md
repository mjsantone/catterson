# An agent that accounts for itself

## A split-view review tool that binds each model call to the passage it produced, then lets the reviewer challenge it.

The report sits beside a decision panel. A reviewer needs to see where the agent made a judgment, what evidence it used, and what it left out before deciding whether to rely on the result.

The agent volunteers its weakest call before the reviewer asks. Every call carries its intent, confidence, rejected alternatives, and supporting source. Each one stays bound to the exact part of the report it produced.

The strongest moment is that link. Touch a decision and the report scrolls to and pulses the precise region it shaped. Reasoning you cannot locate in the output is reasoning you cannot check. Binding a call like "I treated the indemnity cap as market-standard, confidence low" to the exact clause lets a professional inspect the assumption where it matters. When the report is sealed inside an iframe, a message bridge carries the highlight across that boundary.

The interaction is turn-taking by design. The agent raises one decision, then waits. Push on a call and it does not fold. It revises when you have a point, and holds, with its reasoning, when you do not. A revision updates the passage with visible track changes; an unanswered question blocks sign-off. Caving to pressure is the failure mode that makes a reviewer stop trusting the tool meant to save them work.

My work is the interaction, call-to-report binding, hold-or-revise contract, tracked revision, sign-off gate, and iframe message bridge; the model supplies the call notes. The weakest point is still text matching: if a call's text is not present verbatim, the highlight quietly does nothing. There is no adoption data yet. What the prototype proves is narrower: an agent can volunteer doubt, defend a supported call, revise a weak one visibly, and refuse premature sign-off instead of handing over an answer and a shrug.
